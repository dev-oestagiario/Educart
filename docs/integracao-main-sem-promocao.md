# Integração de código separada da promoção — atualização 18/11/2026

O usuário autorizou explicitamente integrar o código na main. **A integração do código-fonte não constitui aceite, release ou autorização para publicar/deploy/migrar produção.** Como a main anteriormente acionava publicação automaticamente, o workflow Pages agora exige dispatch manual e dois valores correspondentes ao SHA efetivo: input approved_sha e variável de repositório/ambiente EDUCART_APPROVED_RELEASE_SHA definida pelo responsável após #66–#70. Não configurar essa variável nesta integração. O workflow mantém audit completo e todos os testes anteriores, acrescenta testes operacionais e axe-core isolado. Nenhum gate de promoção foi dispensado. O guard é controle contra promoção acidental, não substitui controles de acesso/revisão do mantenedor nem comprova aceite; a variável não é um segredo e não deve ser definida antecipadamente. CI segue indisponível conforme relato; commits com [skip ci]. Main pode conter código de funcionalidades cujo schema ainda não está publicado; continuar utilizando o serviço hospedado atual até aprovação.
