# Identidade visual — Educart
Direção aprovada: conceito A, monograma E angular com traço lilás.
Referência: https://github.com/kaankiziltug/logo-design-skill

## Mestres vetoriais
- `educart-logo.svg`: logotipo horizontal escuro para fundo claro.
- `educart-logo-light.svg`: logotipo horizontal reverso para fundos escuros.
- `educart-symbol.svg` e `educart-symbol-light.svg`: símbolo isolado.
- `/favicon.svg`: símbolo simplificado, em placa preta, para tamanhos de 16–32 px.

Cores: primária `#201932`; acento `#A88AF5`; reversa `#F6F2FF`; base escura `#1F182E`.
Não aplicar brilhos, gradientes, contornos ou deformações. Não redesenhar as letras no sistema: os arquivos SVG possuem letras convertidas em paths, sem depender de fontes externas.
Respeitar espaço livre mínimo de 1/4 da altura do símbolo ao redor da marca. Tamanhos: logotipo horizontal >=120 px de largura; símbolo isolado >=16 px com a versão otimizada para favicon.
Para o uso no React utilizar `src/components/BrandLogo.tsx`, que respeita o caminho relativo do Vite (`BASE_URL`).

Testes visuais: verificar sobre superfícies claras/escuras, tamanhos 16/32/64/128 px, monocromia e ausência de detalhes finos. A identidade não implica pesquisa ou registro de marca.
